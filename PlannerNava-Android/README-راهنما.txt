نوا | نسخه اندروید با کارنامه، خط زمانی، آمار و ویجت

این پروژه برای ساخت APK در GitHub Actions آماده شده و به نصب Android Studio روی کامپیوتر نیاز ندارد.

امکانات موجود در برنامه:
- خانه، کارها، تقویم شمسی، اهداف، عادت‌ها، یادداشت‌ها و تایمر تمرکز
- کارنامه آزمون‌های تستی و تشریحی در بخش جداگانه و فیلتر ماهانه
- تستی: تعداد کل، صحیح، غلط، نزده، شماره سؤال‌های نزده و درصد دستی یا محاسبه درصد با نمره منفی یک‌سوم
- تشریحی: تعداد کل سؤال‌ها، سؤال‌های غلط، نمره کسب‌شده و نمره از چند
- نمودار ماهانه کارنامه، میانگین درصد تستی، میانگین نمره تشریحی و بهترین درصد
- خط زمانی ۲۴ ساعته بر اساس ساعت شروع و مدت هر کار
- حالت‌های آمار: هفته، ماه، دسته‌بندی، دقایق تمرکز و پایبندی به عادت‌ها
- تم روشن/تیره، رنگ تأکیدی و پشتیبان‌گیری/بازیابی دستی
- ذخیره اطلاعات روی خود دستگاه و ویجت اندروید برای خلاصه کارهای امروز

ساخت APK:
1. یک repository جدید در GitHub بساز.
2. فایل‌های داخل همین پوشه پروژه را در ریشه repository بارگذاری کن. پوشه app، پوشه .github و فایل‌های build.gradle، settings.gradle و gradle.properties باید در ریشه باشند.
3. در GitHub وارد تب Actions شو. اگر لازم بود Actions را فعال کن.
4. گردش‌کار Build Nava APK را اجرا کن یا پس از push شدن به شاخه main منتظر اجرای خودکار بمان.
5. پس از موفق شدن اجرا، صفحه همان اجرای workflow را باز کن و از بخش Artifacts، فایل PlannerNava-debug-apk را دانلود کن.
6. فایل ZIP آرتیفکت را باز کن؛ app-debug.apk داخل آن است. APK را به گوشی منتقل و نصب کن.
7. برنامه را یک بار باز کن، سپس در صفحه اصلی گوشی فضای خالی را نگه دار > Widgets > نوا و ویجت را اضافه کن.

نکات:
- این پروژه سورس آماده ساخت است، نه APK از پیش کامپایل‌شده. ساخت نهایی باید در GitHub Actions موفق شود.
- ویجت خلاصه کارهای امروز را نشان می‌دهد و با لمس آن برنامه باز می‌شود. تیک‌زدن مستقیم کارها از ویجت هنوز پیاده‌سازی نشده است.
- اطلاعات اصلی روی دستگاه می‌ماند. پشتیبان دستی از تنظیمات برنامه گرفته شود.
- اعلان‌های بومی زمان‌بندی‌شده هنوز در این نسخه پیاده‌سازی نشده‌اند.
